# Bug Reports

No confirmed functional defect has been documented for Portfolio V1.

During automation, the site presented some markup limitations that required narrowly scoped CSS locators, including an icon-only search button, a cart modal without a usable dialog role, and an incorrectly associated Zipcode label. These observations were used to choose reliable locators; they have not been classified as functional bugs or included in defect metrics.

Future defects will be added only after reproduction with environment, severity, preconditions, steps, expected result, actual result, and real evidence.
